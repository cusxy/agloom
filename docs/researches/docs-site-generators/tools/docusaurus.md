# Docusaurus

## Описание

Docusaurus -- open-source SSG от Meta, построенный на React. Разработан
для стандартизации документации open-source проектов Facebook. Текущая
стабильная версия -- 3.9.2. Поддерживает MDX, версионирование, i18n,
плагинную систему.

Используется React Native, Redux Toolkit, Prettier, Supabase, Algolia,
Hasura и тысячами open-source проектов.

## Оценка по критериям

### K1. Совместимость стека

Node.js экосистема, установка через npm/pnpm. React-based -- отличается
от стека agloom (Ink использует React, но для CLI, не для веба).
Конфигурация в `docusaurus.config.js` (JavaScript, TypeScript через
wrapper).

### K2. Landing page

Полноценные кастомные страницы на React. Шаблон включает landing page
с hero, features и call-to-action. Наиболее гибкий из рассмотренных
инструментов для создания landing page произвольной сложности.

### K3. Sidebar ordering

Нативная поддержка через frontmatter `sidebar_position`:

```yaml
---
sidebar_position: 2
---
```

Автогенерация sidebar по файловой структуре. Альтернатива -- числовые
префиксы в именах файлов. Категории (директории) настраиваются через
`_category_.json`.

### K4. Markdown + frontmatter

MDX -- Markdown с React-компонентами. YAML frontmatter поддерживается
нативно. Расширенные возможности: tabs, admonitions, code blocks
с подсветкой.

### K5. Поиск

Интеграция с Algolia DocSearch (бесплатно для open-source).
Встроенный local search доступен через community-плагины.
Для open-source проектов Algolia DocSearch -- качественное решение.

### K6. DX и производительность

- Webpack-based билд: медленнее Vite-based решений.
- Dev-сервер: заметно медленнее VitePress.
- Более сложная конфигурация из-за обилия опций.
- Тяжёлый React-бандл на клиенте.

### K7. Зрелость экосистемы

- ~3M еженедельных загрузок npm -- наибольшее adoption.
- Стабильный API, поддержка Meta.
- Огромная экосистема плагинов и тем.
- Активное сообщество и регулярные релизы.

## Плюсы

- Наибольшее сообщество и экосистема плагинов.
- Встроенное версионирование документации.
- Полноценные кастомные React-страницы для landing.
- Нативный sidebar ordering через frontmatter.
- Algolia DocSearch бесплатно для open-source.
- Стабильность и долгосрочная поддержка (Meta).

## Минусы

- Webpack-based: медленнее Vite-based решений в dev и build.
- Тяжёлый React-бандл (~300 KB+ JS на клиенте).
- Стилевая система Infima ограничивает кастомизацию CSS (нет Tailwind
  интеграции из коробки).
- Избыточен для масштаба agloom (~15 страниц): версионирование, i18n,
  плагинная система -- неиспользуемая сложность.
- Более высокий порог входа в конфигурацию.

## Контекст применимости

**Оправдан**: крупные open-source проекты с потребностью в версионировании,
i18n, кастомных страницах на React, и команда уже в React-экосистеме.

**Не оправдан**: малые проекты, где избыточная функциональность создаёт
лишнюю сложность, или когда скорость билда критична.
