# Настройка Docusaurus и Cloudflare Pages

Ключевые слова «ТРЕБУЕТСЯ», «ЗАПРЕЩАЕТСЯ», «ДОЛЖЕН», «НЕ ДОЛЖЕН», «СЛЕДУЕТ»,
«НЕ СЛЕДУЕТ», «МОЖЕТ» и «НЕОБЯЗАТЕЛЬНО» в этом документе толкуются
в соответствии с [RFC 2119](https://tools.ietf.org/html/rfc2119).

Данная спецификация описывает настройку документационного сайта Agloom:
Docusaurus v3 в директории `website/`, интеграцию с pnpm workspace
и деплой на Cloudflare Pages. Выбор инструментов обоснован
в `docs/researches/docs-site-generators/RESEARCH.md`
и `docs/researches/hosting/RESEARCH.md`.

Содержимое документации (`docs/guide/`, `docs/reference/`) описано
в `docs/specs/docs-structure.md` и не входит в scope данной спецификации.

## Структура директории website/

Директория `website/` ДОЛЖНА располагаться в корне репозитория.

```text
website/
├── package.json
├── docusaurus.config.ts
├── tsconfig.json
├── sidebars.ts
├── static/
│   └── _redirects
├── src/
│   ├── pages/
│   │   └── index.tsx
│   └── css/
│       └── custom.css
└── build/              (gitignored)
```

## package.json

Файл `website/package.json` ДОЛЖЕН содержать:

- `name` — `"@agloom/website"`.
- `version` — `"0.0.0"` (приватный пакет, не публикуется).
- `private` — `true`.
- `scripts`:
  - `start` — `"docusaurus start"`.
  - `build:site` — `"docusaurus build"`.
  - `clear` — `"docusaurus clear"`.
  - `serve` — `"docusaurus serve"`.
- `dependencies`:
  - `@docusaurus/core` — `^3`.
  - `@docusaurus/preset-classic` — `^3`.
  - `react` — `^19`.
  - `react-dom` — `^19`.
- `devDependencies`:
  - `@docusaurus/module-type-aliases` — `^3`.
  - `@docusaurus/types` — `^3`.
  - `typescript` — `^5`.
- `engines`:
  - `node` — `">=20"`.

## Конфигурация Docusaurus

Файл `website/docusaurus.config.ts` ДОЛЖЕН экспортировать объект конфигурации
со следующими параметрами.

### Основные параметры

- `title` — `"Agloom"`.
- `tagline` — `"Transpile canonical agent configurations across AI coding assistants"`.
- `url` — `"https://agloom.sh"`.
- `baseUrl` — `"/"`.
- `organizationName` — `"cusxy"`.
- `projectName` — `"agloom"`.
- `onBrokenLinks` — `"throw"`.
- `onBrokenMarkdownLinks` — `"throw"`.
- `favicon` — поле НЕ ДОЛЖНО быть указано. Favicon не входит в scope.

### Preset classic

Конфигурация ДОЛЖНА использовать `@docusaurus/preset-classic` с параметрами:

- `docs`:
  - `path` — `"../docs"`. Документация расположена в корне репозитория
    (`docs/`), не в `website/`.
  - `routeBasePath` — `"docs"`. Документация доступна по пути `/docs/`.
  - `sidebarPath` — `"./sidebars.ts"`.
- `theme`:
  - `customCss` — `"./src/css/custom.css"`.
- `blog` — `false`. Блог не используется.

### Sidebar

Файл `website/sidebars.ts` ДОЛЖЕН определять sidebar с двумя категориями:

- Категория `"Guide"` — autogenerated из `docs/guide/`.
  Порядок элементов определяется полем `sidebar_position` в YAML frontmatter
  каждого файла.
- Категория `"Reference"` — autogenerated из `docs/reference/`.
  Порядок элементов определяется полем `sidebar_position` в YAML frontmatter
  каждого файла.

Формат — `SidebarsConfig` с `type: "autogenerated"` и `dirName`
для каждой категории:

```ts
const sidebars: SidebarsConfig = {
  docs: [
    {
      type: "category",
      label: "Guide",
      items: [{ type: "autogenerated", dirName: "guide" }],
    },
    {
      type: "category",
      label: "Reference",
      items: [{ type: "autogenerated", dirName: "reference" }],
    },
  ],
};
```

### Theme и navbar

Конфигурация `themeConfig` ДОЛЖНА содержать:

- `colorMode`:
  - `defaultMode` — `"dark"`.
  - `respectPrefersColorScheme` — `true`.
- `navbar`:
  - `title` — `"Agloom"`.
  - `items`:
    - Ссылка на Guide: `{ type: "docSidebar", sidebarId: "docs", label: "Docs", position: "left" }`.
    - Ссылка на GitHub: `{ href: "https://github.com/cusxy/agloom", label: "GitHub", position: "right" }`.
- `footer`:
  - `style` — `"dark"`.
  - `copyright` — `"Copyright © {year} Agloom contributors. Apache-2.0 License."`,
    где `{year}` вычисляется через `new Date().getFullYear()`.

### TypeScript конфигурация

Файл `website/tsconfig.json` ДОЛЖЕН расширять конфигурацию Docusaurus:

```json
{
  "extends": "@docusaurus/tsconfig",
  "compilerOptions": {
    "baseUrl": "."
  }
}
```

## Landing page

Файл `website/src/pages/index.tsx` ДОЛЖЕН реализовать landing page,
доступную по пути `/`.

Landing page ДОЛЖНА содержать:

1. **Hero-секция** — название проекта (`"Agloom"`), tagline
   (значение из `docusaurus.config.ts` `tagline`), кнопка
   `"Get Started"` со ссылкой на `/docs/guide/introduction`.
2. **Минимальная структура** — hero-секция является достаточным содержимым.
   Дополнительные секции (features, examples) не входят в scope.

Компонент ДОЛЖЕН использовать `@docusaurus/Link` для навигации
и `useDocusaurusContext` для доступа к `siteConfig`.

## Стили

Файл `website/src/css/custom.css` ДОЛЖЕН содержать минимальную
кастомизацию цветовой палитры Docusaurus (CSS custom properties
для `--ifm-color-primary` и связанных переменных) для светлой
и тёмной тем.

## Workspace интеграция

### pnpm-workspace.yaml

Файл `pnpm-workspace.yaml` в корне репозитория ДОЛЖЕН быть обновлён —
`website` ДОЛЖЕН быть добавлен в список workspace packages:

```yaml
packages:
  - "packages/*"
  - "website"
```

### turbo.json

Файл `turbo.json` НЕ ДОЛЖЕН быть изменён. Пакет `website`
НЕ ДОЛЖЕН участвовать в pipeline задач `build`, `test`, `lint`,
`fmt`, `fmt:check`, определённых в `turbo.json`, потому что website
имеет собственный build pipeline (Docusaurus), несовместимый
с общим (TypeScript compiler).

Turbo запускает задачу для пакета, только если в его `package.json`
определён скрипт с соответствующим именем. Пакет `website`
НЕ ДОЛЖЕН определять скрипты с именами, совпадающими с задачами
turbo pipeline (`build`, `test`, `lint`, `fmt`, `fmt:check`).

Имена скриптов в `website/package.json` (см. § package.json)
выбраны так, чтобы избежать коллизии с задачами turbo pipeline:
скрипт сборки ДОЛЖЕН называться `build:site` (не `build`).

### .gitignore

Файл `.gitignore` в корне репозитория ДОЛЖЕН быть дополнен записями:

```gitignore
# Docusaurus
website/build/
website/.docusaurus/
website/node_modules/
```

## Cloudflare Pages

### Build конфигурация

Cloudflare Pages project ДОЛЖЕН быть настроен со следующими параметрами:

- **Framework preset** — None (custom build).
- **Build command** — `cd website && pnpm install && pnpm run build:site`.
- **Build output directory** — `website/build`.
- **Root directory** — `/` (корень репозитория).
- **Environment variables**:
  - `NODE_VERSION` — `20`.
  - `PNPM_VERSION` — `10`.

### Домены

Cloudflare Pages project ДОЛЖЕН обслуживать два домена:

1. **`agloom.sh`** — основной домен. Landing page доступна на `/`,
   документация на `/docs/`.
2. **`docs.agloom.sh`** — CNAME на Cloudflare Pages. Обслуживает тот же
   build, но через Cloudflare rewrite отдаёт `/docs/` контент напрямую
   на корневом пути.

### Redirect для agloom.ai

Домен `agloom.ai` ДОЛЖЕН быть настроен как HTTP redirect (301)
на `https://agloom.sh`. Redirect настраивается через Cloudflare DNS
(Page Rule или Redirect Rule), не через код приложения.

### Файл \_redirects

Файл `website/static/_redirects` ДОЛЖЕН содержать правила
для Cloudflare Pages. Cloudflare Pages поддерживает файл `_redirects`
в output directory для декларативных redirect/rewrite правил.

Правило для `docs.agloom.sh`:

```text
https://docs.agloom.sh/* /docs/:splat 200
```

Это rewrite (код 200) — URL в браузере остаётся `docs.agloom.sh/introduction`,
но отдаётся контент `/docs/introduction`.

## Вне scope

- Содержимое документации (`docs/guide/`, `docs/reference/`) —
  описано в `docs/specs/docs-structure.md`.
- Кастомные Docusaurus-плагины.
- Algolia DocSearch или иная поисковая интеграция.
- Аналитика (Google Analytics, Plausible и т.п.).
- CI/CD pipeline для автодеплоя (GitHub Actions) — описан
  в `docs/specs/ci-deploy.md`.
- Визуальный дизайн, кастомная тема, логотип.
- Мультиязычность (i18n).
- Versioned docs.
