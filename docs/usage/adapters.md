# Adapters

List available or active adapters.

## Usage

```
agloom adapters [--all]
```

## Options

- `--all` — show all available adapters, not just those configured in `.agloom/config.yml`.

## Examples

Show active adapters from config:

```
agloom adapters
```

Show all available adapters:

```
agloom adapters --all
```
