# Постмортем: `agloom init --all` создаёт пустые директории

**Дата:** 2026-03-27
**Severity:** low
**Статус:** исправлено

## Описание бага

При выполнении `agloom init --all` создавались пустые директории:
- `.agloom/overlays/agentsmd/`
- `.agloom/overlays/opencode/`
- `.agloom/project/`

Эти директории не должны существовать, если нет файлов для копирования.

## Корневая причина

В `src/cli/init-files.ts` обе функции (`initFiles` и `backupProjectFiles`)
вызывали `fs.mkdirSync(targetDir, { recursive: true })` **безусловно**,
до проверки наличия файлов для копирования.

### `initFiles` (overlay-директории)

```
Шаг 3: mkdirSync → создать .agloom/overlays/{id}/     ← создаётся всегда
Шаг 4: проверить targetRoot                            ← если не существует → return {copiedCount: 0}
```

Директория создавалась на шаге 3, а на шаге 4 функция возвращала ранний
результат `{ copiedCount: 0, errors: [] }` — пустая директория оставалась.

### `backupProjectFiles` (project-директория)

```
Шаг 8: mkdirSync → создать .agloom/project/            ← создаётся всегда
Шаги 9-10: цикл копирования                            ← если foundFiles пуст → пустая директория
```

Аналогично: директория создавалась до проверки количества найденных файлов.

## Исправление

### `initFiles`

Перенесли проверку `targetRoot` и `discoverFiles` **до** вызова `mkdirSync`.
Добавили early return если `files.length === 0`.

### `backupProjectFiles`

Добавили early return `if (foundFiles.length === 0)` **до** вызова `mkdirSync`.

## Затронутые файлы

- `src/cli/init-files.ts` — исправление логики создания директорий.
- `src/cli/__tests__/init-command.spec.ts` — 3 регрессионных теста.

## Регрессионные тесты

1. `не создаёт пустую overlay-директорию если targetRoot не существует`
2. `при --all не создаёт пустые overlay-директории для адаптеров без файлов`
3. `не создаёт пустую .agloom/project/ если project-файлов нет`

## Уроки

- При создании директорий для копирования файлов — сначала проверять наличие
  файлов, затем создавать директорию. Принцип: не создавать файловые артефакты
  без содержимого.
- Спецификация описывала шаги в порядке "создать директорию → скопировать файлы",
  что провоцировало реализацию с безусловным созданием. Следует учитывать
  edge case "0 файлов" при проектировании последовательности шагов.
