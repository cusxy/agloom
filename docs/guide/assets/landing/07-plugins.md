## Content

**Eyebrow:** `PLUGINS`

**H2:** Three lines of config. A whole team's worth of conventions.

**Body (short):**

> A plugin is a directory with a `plugin.yml` manifest and the same structure as a local project. Reference it by git URL or local path, optionally passing values for variables the plugin declares. Plugins stack in declaration order — later plugins and the local project override earlier ones.

---

### Before → After

**Left — `.agloom/config.yml`:**

```yaml
adapters:
  - claude
  - codex
  - gemini
  - opencode

plugins:
  - git@github.com:acme/agloom-base#v3.1.0
  - git: git@github.com:acme/agloom-conventions
    ref: v1.2.0
    values:
      team_name: "platform"
  - ../shared/android-stack
```

**Caption:**

> Plugins can declare typed variables (`description`, `default`, `required`, `sensitive`). Sensitive values must come from environment variables — Agloom rejects inline secrets so they never end up in commits. [Learn more about plugins →](/docs/plugins)
