# type: doc

**Назначение.** Информационный документ без жизненного цикла.
Описывает архитектуру, конвенции, планы, процессы. Не управляет
имплементацией напрямую — служит справочным материалом.

## Front matter

Общие поля — см. `index.md` → «Документационный front matter».

Поля `status` и `maps_to` неприменимы.

## Структура

Свободная. Содержимое определяется назначением документа.
