# type: skill

**Назначение.** Определение скилла — оркестратора, работающего
inline в основном контексте Claude Code. Управляет запуском агентов
или выполнением процедуры. Файл `SKILL.md` в папке скилла.

Рекомендуемые секции описывают паттерн **циклирующего оркестратора** —
скилл, управляющий парами агентов (исполнитель → reviewer) в цикле
с quality gates, возвратами при fail и сводкой по завершении.

## Front matter

Скиллы используют собственный формат front matter:

| Поле          | Тип    | Обязательность | Описание                    |
| ------------- | ------ | -------------- | --------------------------- |
| `name`        | string | ТРЕБУЕТСЯ      | Идентификатор скилла        |
| `description` | string | ТРЕБУЕТСЯ      | Краткое описание назначения |

## Структура

Свободная. Содержимое определяется сложностью скилла.

РЕКОМЕНДУЕТСЯ для циклирующего оркестратора:

- Секция «Принцип работы» — механизм управления агентами, формат ввода/вывода.
- Секция «Цикл» — граф переходов между агентами, логика возвратов.
- Definition of Ready — предусловия запуска цикла.
- Definition of Done — условия завершения цикла.
- Секция «Обработка ошибок» — поведение при повторных fail, зацикливании.
- Секция «Сводка» — формат вывода результатов.

## Тон и стиль

Скиллы используют второе лицо (директивные инструкции
с RFC 2119 keywords), потому что скилл — инструкция для LLM,
работающего в сессии пользователя.

## Валидация

| #   | Правило                                                        | Тип           |
| --- | -------------------------------------------------------------- | ------------- |
| K1  | Инструкции написаны во втором лице                             | Семантическое |
| K2  | Описан формат ввода                                            | Семантическое |
| K3  | Описан порядок действий                                        | Семантическое |
| K4  | Нет разговорной лексики, сленга и неформальных сокращений      | Семантическое |
| K5  | Для циклирующего скилла — описан граф переходов между агентами | Семантическое |
| K6  | Для циклирующего скилла — описана логика возвратов при fail    | Семантическое |
