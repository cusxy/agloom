# type: index

**Назначение.** Общее описание концепции, за которую отвечает папка,
и общие положения, являющиеся пререквизитом для остальных файлов в папке.

## Front matter

Общие поля — см. `index.md` → «Документационный front matter».

Поля `status` и `maps_to` неприменимы.

## Структура

Свободная. Содержимое определяется назначением папки.

## Ограничения

- ТРЕБУЕТСЯ один `index.md` на папку с markdown-документами.
- При чтении любого файла из папки — `index.md` обязателен к прочтению.

## Валидация

| #   | Правило                                     | Тип         |
| --- | ------------------------------------------- | ----------- |
| I1  | Файл называется `index.md`                  | Структурное |
| I2  | Front matter содержит `type: index`         | Структурное |
| I3  | В папке не более одного файла с type: index | Структурное |
| I4  | Отсутствует поле `status`                   | Структурное |
| I5  | Отсутствует поле `maps_to`                  | Структурное |
